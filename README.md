# SystemVerilog Design & Verification Practice

Practice labs from the **Cadence SystemVerilog Design & Verification** course.  
Focused on RTL design and functional verification using industry-standard tools.

## 🛠️ Tools & Language
- **Language**: SystemVerilog
- **Curriculum**: Cadence Learning (System Verilog Design & Verification)
- **Simulator**: Cadence Xcelium (or whichever you use)

## 📁 Repository Structure

### `basic_blocks/`
Fundamental RTL building blocks:

| File | Description |
|------|-------------|
| `register.sv` | 8-bit register with async reset and enable signal |
| `scale_mux.sv` | Parameterized 2-to-1 multiplexer |

### `riscv-verification/` *(coming soon)*
Functional verification of a RISC-V processor core  
based on Cadence verification curriculum.
